# tvadblock-max

TizenBrew site-modification module: the max website with uBlock Origin's own scriptlets and the uAssets rules for it injected at document start.

Built from gorhill/uBlock (1e6f82b) and uBlockOrigin/uAssets (e2c4b48); every rule carries its source file:line in the build. GPLv3.

Add in TizenBrew: `gh/<user>/tvadblock-max`
